# API Changelog

We aim at not making breaking changes within each major version of the API. However, new fields may be added at any time. All changes will be listed here.

### November 25, 2026

- `POST /v3/tasks/close` and `POST /v3/tasks/reopen` no longer accept `occurrenceStart`. To complete or reopen one scheduled session or occurrence, set `morgen.so:metadata.progress` with `POST /v3/events/update`. See [Completing a Task Session or Occurrence](/events#completing-a-task-session-or-occurrence).

### January 9, 2026

- Published Morgen Task API
